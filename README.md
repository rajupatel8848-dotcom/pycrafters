# Pycrafters website

Static site: open `index.html` in a browser or upload the folder to any host (Netlify, Vercel, GitHub Pages, cPanel).

## Structure
- `index.html` — all page content (hero, about, services, why, work, process, FAQ, footer)
- `css/styles.css` — all styles (footer colour `#00555A` is set at the end of the file)
- `js/main.js` — menu, animations, work-section scroll slider, WhatsApp links
- `assets/images/` — the four project images
- `404.html`, `robots.txt`, `sitemap.xml` — replace `YOUR-DOMAIN.com` with your real domain
